# 借地権の計算ツール（WordPressプラグイン）

借地権の売却相場・更新料・承諾料の目安を出す3つのツールを、ショートコード1本でページに置ける。
ミカタ株式会社の資産。お寺の借地権.com（cv-n65.jp）向けに作った。

- プラグイン本体: `shakuchi-tools/shakuchi-tools.php`（設定・REST・ショートコード・管理画面）
- 掛け率の定義と既定値: `shakuchi-tools/includes/rates.php`
- 見出し・導入文・解説・出典: `shakuchi-tools/includes/tools-data.php`
- 共通エンジン（フォーム生成・結果描画）: `shakuchi-tools/assets/skt.js`（fudosan-tools の ftl.js から複製）
- 各ツールの計算と土地の単価の欄: `shakuchi-tools/assets/skt-tools.js`
- 市区町村マスタ: `shakuchi-tools/includes/jp-cities.php`（fudosan-satei と同じもの）
- 配信元: https://github.com/yoshimucom-gif/shakuchi-tools-plugin

識別子は `SKT_*` / `skt_*` / CSS `skt-*`、設定は単一オプション `skt_options`、
設定画面は「設定 → 借地権ツール」。DBテーブルは作らない。

## 計算のしかた

```
更地価格   = 土地の㎡単価 × 面積
借地権価格 = 更地価格 × 借地権割合（路線価図のA〜G。不明なら60%と70%の両方）
結果       = 上に管理画面の掛け率（下限〜上限）を掛けた幅
```

土地の㎡単価は3通り:

| 取り方 | 中身 |
|---|---|
| 住所から自動 | 国交省 XIT001 の「宅地(土地)」、前年までの8四半期。町名で5件以上あれば町名、無ければ市区町村全体（その旨を表示）。**中央値**を使い、25〜75%の幅は注記に出す |
| 路線価 | 千円/㎡。0.8で割り戻して時価の目安にする（路線価は公示価格の8割程度） |
| 坪単価 | 万円/坪。3.30578で㎡に直す |

土地の単価を中央値にしているのは、取引の幅まで掛けると借地権割合の幅・掛け率の幅と3重に広がり、
目安として使えなくなるため（目黒区で実測: 3,000万〜7,840万円 → 中央値なら3,600万〜5,880万円）。

## 設計上の決めごと

- **APIキーが無いとき、ダミーの取引事例に落とさない。** 架空の事例を「周辺の取引」として見せることになる
  （fudosan-satei と同じ判断）。キーが無ければ「住所から自動」の選択肢そのものを出さない。
- APIキーはこのプラグインの設定が空なら、同じサイトの fudosan-souba（`fsb_options`）のキーを使う。
- 国交省APIの結果は12時間キャッシュ。キャッシュキーにAPIキーの指紋を入れる（キーを替えたら取り直す）。
  全四半期とも失敗した結果はキャッシュしない。
- `/wp-json/skt/v1/land` は未ログインで叩ける。市区町村コードを実在マスタと照合し、IPごとに10分60回まで。
- **表記は「参考価格の目安」。** ミカタは宅建業者ではないので、自動計算の結果を「査定」と呼ばない。
  「査定」と書くのはボタンの先（監修の宅建業者）だけ。
- 解説の中の掛け率は `{jinushi}` のような差し込み記号で書き、描画時に設定値へ置き換える。
  設定を変えても、解説・結果の注記・計算がずれない。
- 相談フォームへの引き継ぎは sessionStorage（URLに載せない・1時間で破棄・本文欄が空のときだけ書く）。
  Contact Form 7 の欄名は設定で変えられる（既定は cv-n65.jp のフォーム: `your-message` / `youken` / `tera`）。
- GA4 のイベント: `skt_use`（最初に入力を触ったとき1回）、`skt_cta_click`（ボタン）。パラメータ `tool`。

## 掛け率（★既定値は暫定・監修確認待ち）

`includes/rates.php` の `skt_rate_spec()`。管理画面で下限〜上限を％で変えられる。
確定したら既定値も直して版を上げ、管理画面の「監修者に確認済み」にチェックを入れる。

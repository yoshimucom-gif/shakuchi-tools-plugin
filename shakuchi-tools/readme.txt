借地権の売却相場・更新料・承諾料の目安を、ショートコード1本でページに置けます。

== 説明 ==

1. 借地権の売却相場シミュレーター … [shakuchi_tool name="baikyaku"]
2. 借地権の更新料 計算ツール … [shakuchi_tool name="koushin"]
3. 借地権の承諾料 計算ツール … [shakuchi_tool name="shoudaku"]

土地の単価は「住所から自動（国土交通省 不動産情報ライブラリ）」「路線価」「坪単価」の3通りで入れられます。
自動取得は、設定 → 借地権ツール でAPIキーを入れたときだけ表示されます。

= 属性 =

* head="off" … 見出しと導入文を出さない（記事の途中に埋めるとき）
* desc="off" … 解説を出さない
* cta="off" … 結果の下のボタンを出さない
* title="…" … 見出しを差し替える

== 注意 ==

結果は参考価格の目安です。不動産鑑定評価や、宅地建物取引業者による価格査定ではありません。
掛け率は 設定 → 借地権ツール で変えられます。
